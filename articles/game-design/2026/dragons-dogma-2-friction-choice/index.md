# 『ドラゴンズドグマ 2』大改修アプデの“冒険を楽にする新機能”は、批判覚悟で実装していた。たしかな手応えで迎える『ダークアリズン』、そのこだわりを訊いた

## 這篇在談甚麼

《Dragon's Dogma 2》原本刻意讓旅行帶有阻力：快速旅行受限制、玩家需要實際走過世界，途中可能遇到戰鬥與意外。這些限制既是作品的特色，也是部分玩家最不滿的地方。

AUTOMATON 在 TGS 2026 訪問《Dark Arisen》導演木下研人與製作人大山直人。訪談最有價值的部分不是 DLC 新內容，而是團隊如何理解本篇推出後的玩家反應，以及為甚麼後續更新選擇增加便利功能，卻沒有直接把原本的旅行設計拆掉。

## Friction 和 Frustration 可能是同一套系統的兩種讀法

團隊觀察到明顯的地區傾向：部分歐美玩家把難以快速旅行、必須承受旅途風險等設計理解為 **friction**，也就是讓冒險具有重量的阻力；日本及亞洲玩家則較常把同一類限制理解成 **frustration**，希望遊戲更方便。

這不是嚴格的玩家研究，團隊也明確表示每個地區內都同時存在兩種玩家，因此不能把它當成文化定律。但它讓開發團隊面對一個很實際的問題：

```text
拿掉限制
→ 喜歡原本旅途重量的人失去作品特色

維持限制
→ 覺得重複移動已經沒有價值的人繼續承受成本
```

他們最後選擇的不是二選一，而是增加新的可選工具。

## 把便利做成選項，而不是改寫所有人的規則

更新加入可以重複使用的快速旅行道具「刹那の永久石」，牛車亦增加中途下車等功能。玩家可以完全不用這些工具，繼續按照原本方式旅行；也可以在自己認為路程已經沒有新內容時縮短移動。

製作人大山直人用登山比喻這種設計：有人從山腳走上去，也有人坐纜車到較高處再開始走。團隊希望穩定的是到達目標時的滿足感，而讓玩家自行調節抵達之前的過程。

這裡最重要的不是「加了 Fast Travel」，而是把設計問題拆成：

```text
Goal / Payoff
    ↑
希望維持

Process / Cost
    ↑
允許玩家調節
```

## 第一次探索與重複路程不是同一個問題

木下研人特別指出，快速旅行並不能直接用在第一次前往的地方。團隊認為第一次踏入未知區域、克服沿途戰鬥並抵達目的地，是《Dragon's Dogma 2》冒險感最重要的一部分，因此沒有讓便利功能跳過這一段。

相反，當玩家已經多次走過相同道路，途中也不再產生新變化時，原本有意義的 friction 可能只剩下重複成本。

可以把它理解成：

```text
第一次路程
未知 + 風險 + 發現
→ 路程本身就是內容

第十次路程
已知 + 重複 + 幾乎沒有新事件
→ 路程可能逐漸變成操作成本
```

因此問題不是「快速旅行好不好」，而是 **同一段等待或移動成本在不同資訊狀態下，是否仍然產生體驗價值**。

## Loot 也使用類似的「保留隨機性，但讓玩家能干預」思路

《Dark Arisen》的遺戰品帶有隨機掉落與技能組合。如果完全依賴 RNG，玩家為了特定裝備可能需要無限重複同一內容。

團隊沒有把隨機性取消，而是讓玩家與 Main Pawn 的職業影響相應武器掉率，並提供 Buff 進一步縮小掉落範圍，例如提高 Fighter 劍的出現機率。

另一方面，地圖深處通常會出現較高等級的裝備，但並非完全鎖死。玩家若提早闖入危險區域並成功戰勝敵人，仍有機會取得超出正常進度的裝備。

所以這裡再次出現相同結構：

```text
Randomness / World Progression
          +
Player-controlled Bias
          ↓
保留意外，但降低無限刷取的無力感
```

## 閱讀時需要知道的前提

這是一篇開發者訪談，不是有完整玩家數據的研究。所謂亞洲與歐美玩家對 friction 的差異來自團隊收到的反應，文章沒有提供樣本數、統計方法或平台分布，因此適合視為開發者的實務觀察，而不是一般化的文化結論。

另外，《Dark Arisen》尚未正式推出，Loot 與新區域設計目前主要反映 Design Intent；最終是否真的能在便利與冒險重量之間取得平衡，仍要看實際玩家行為。

## 我的筆記與延伸

這篇最值得留下的問題是：**friction 的價值可能會隨玩家知道多少而改變。**

同樣是走十分鐘，第一次可能包含導航、未知敵人、資源管理和發現；第五次若世界狀態沒有足夠變化，就可能只剩下時間成本。因此「是否保留 friction」不能只看操作本身，而要看它在當下仍然承載多少資訊與決策。

另一個有意思的地方，是團隊沒有把 Accessibility／Convenience 理解成全域規則，而是盡量做成玩家可控制的介面。這種方法的限制也很明顯：只要某個便利選項在效率上壓倒性地優越，即使名義上是 Optional，玩家仍可能感到被迫使用。因此真正的問題仍然是不同路徑是否各自保有足夠的體驗價值，而不是單純「有選項就好」。
